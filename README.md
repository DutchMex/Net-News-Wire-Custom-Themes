# Net-News-Wire-Custom-Themes

This is the home for my personal edition of the Net News Wire themes.

DutchMex is the main theme, but if I add more themes I will put the files in here.

## DutchMex

I should probably change its name to something fancier, but it’s the only one for now.

This theme relies on two important fonts, [Atkinson Hyperlegible](https://www.brailleinstitute.org/freefont/), and [Maple Mono NF](https://font.subf.dev/en/).

Currently, it has no fallback for those fonts, so if they are not installed on your system, the theme will not work. You only need the “Regular” version of each font, but the full fonts are included in the `.zip` files.

The fonts can be downloaded from the links above, or downloaded either from the `.ttf` files in `Fonts/` or the `.zip` files in that same folder.
